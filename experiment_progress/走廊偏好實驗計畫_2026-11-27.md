## 1. 已經知道的（寫計畫前已經看過的資料，照實列出）

- 母體：E1 和 E1r 的 S 組（總長 ≤ 13 格，時間夠），共 24 個情境，每個 64 條計畫。Diffuser 只拿到起點（靜止）和終點，**不知道障礙物**；「經過 b」是事後用障礙格檢查計畫的結果。
- 結果 y = 該情境 64 條裡**沒有經過 b 的比例**。這 24 個 y 我已經看過：E1 的 12 個裡 10 個是極端值（≤ 0.09 或 ≥ 0.86），E1r 的 12 個裡 6 個在 0.15–0.85 之間。
- 11/27 對話裡的快速對照（事後、只有 E1 的 12 個）：訓練資料裡 A → G 片段避開 b 的比例和 y 的 Pearson 相關 = −0.05。E1r 的資料比例還沒算過。
- 還沒算過的：兩條候選路線離 A–G 直線多遠（第 2 節的 F1）、去噪過程中的計畫（F3）、從指定路線開始去噪（F4）。

## 2. 假說和實驗

**候選解釋**

| 代號 | 說法 |
|---|---|
| 資料頻率 | 模型照訓練資料裡各條走廊出現的比例抽 |
| 直線 | 去噪早期，模型只依起點、終點猜出一條接近 A–G 直線的粗略軌跡；之後被吸到離這條線最近的走廊 |
| 早期決定 | 不管是哪種幾何，走廊在去噪的早期（高噪聲）就定下來，後面只修細節 |

**F1 直線（主要，不用模型）**。每個情境兩條候選路線（格子中心連成的折線）：
- R_b：BFS A → b 接 BFS b → G（經過 b 的最短路）。
- R_d：堵住 b 後的 BFS A → G（繞路）。
- d(R) = 沿 R 的弧長等距取 200 點，到線段 [A 中心, G 中心] 的平均距離（單位：格）。
- Δ = d(R_d) − d(R_b)。Δ < 0 表示繞路比較貼近直線。

**F2 資料頻率（次要）**。E2 的做法（`budget_dataset.py`）擴充到 E1r 的情境。x = 訓練資料裡 A → G 片段避開 b 的比例（n_avoid_b / n_segments）。另外記錄 384 步內的片段數，只做描述。輸出到新的 `results/diag/corridor/e2_all/`，不改已 commit 的 E2。

**F3 去噪軌跡（機制）**。用和 E1/E1r 完全相同的種子重跑 24 個 S 情境（先檢查最後的經過 b 數和已存的 rows 一致），在模型的前向計算上掛 hook，記下 256 步裡每一步模型預測的乾淨軌跡 x̂0（照原本的程式 clamp 到 [−1, 1]，再反正規化）。第 j 步（j = 0 是第一步、噪聲最大；j = 255 是最後一步）：
- v_j：x̂0 有沒有點落在 b 格。
- 定案步數 L：最小的 j，使 j 之後每一步的 v 都等於最後的 v。
- 散布 S_j：同一情境 64 條 x̂0 兩兩之間的平均逐點距離。
- 距離：x̂0 各點到 A–G 線段的平均距離 D_line，到 R_b、R_d 折線的平均最近距離 D_b、D_d。
- 和最後結果的一致率：j ∈ {0, 16, 32, 64, 128} 時 v_j 等於最後 v 的比例。

**F4 從指定路線開始去噪（因果，介入）**。參考軌跡沿 R_d（繞路）或 R_b（經過 b）等速移動，第 359 步到 G、之後停住（同去噪探針的 `reference`），速度 = 位移 / dt，動作 = 0。正規化後在噪聲層級 k − 1 加噪（`q_sample`），從第 k 步開始照原本的 `p_sample` 去噪到 0，每步 `apply_conditioning`。k ∈ {64, 128, 192}（256 步裡剩下的步數，k 越大加的噪聲越多），每個情境、每種路線、每個 k 抽 32 條，用 E1 的方式評分（intact、clear、valid、經過 b）。

## 3. 判讀規則

相關都用 Spearman ρ，p 值用置換檢定（10000 次，固定種子，雙尾）。

**F1 直線**（24 個情境，ρ(Δ, y)）：
- 支持：ρ ≤ −0.5 且 p < 0.05。
- 不支持：ρ > −0.25。
- 其他：不確定。
- 只做描述：|Δ| ≥ 0.2 格的情境裡，「Δ < 0」和「y > 0.5」一致的比例。

**F2 資料頻率**（24 個情境，ρ(x, y)；E1 的一半已經看過，所以另外報告 E1r 的 12 個，只做描述）：
- 支持：ρ ≥ 0.5 且 p < 0.05。
- 不支持：ρ < 0.25。
- 其他：不確定。

**F3 早期決定**（全部 1536 條）：
- 重現檢查：每個情境最後的經過 b 數要和已存的 rows 完全一樣；不一樣就照實報告，改用重跑的結果。
- 早期決定：L 的中位數 ≤ 64（前四分之一）。
- 晚期決定：L 的中位數 ≥ 192。
- 其他：中期。
- 直線前提：第 0 步的 x̂0，在至少 2/3 的情境裡（情境內 64 條取平均）D_line < min(D_b, D_d)。
- 只做描述：S_j 的曲線、一致率。

**F4 介入**（24 個情境合併）：
- 基準：E1/E1r 原本的沒經過 b 比例（合併）。
- 早期形狀決定走廊（支持）：k = 192 時，從繞路開始的計畫沒經過 b 的比例 ≥ 0.5，而且比基準高至少 0.3，同時 intact ≥ 0.5。
- 不支持：k = 64 時，從繞路開始的計畫沒經過 b 的比例比基準高不到 0.2（給了幾乎完成的繞路，模型還是改回最短走廊）。
- 其他：不確定。
- 對照：從 R_b 開始的計畫應該大多經過 b；如果沒有，表示建構方式本身有問題，照實報告。

## 4. 各種結果的意思

| F1 | F3 | F4 | 可以寫 |
|---|---|---|---|
| 支持 | 早期 | 支持 | 走廊在去噪早期由起終點的幾何（接近直線的粗略猜測）決定，不是資料頻率。偏好最短走廊，是因為最短走廊通常最貼近直線 |
| 不支持 | 早期 | 支持 | 走廊在早期就由粗略形狀決定，但不是直線距離；是什麼決定，仍是開放問題 |
| 任一 | 晚期 | 不支持 | 偏好是在去噪後段、細節層級強制出來的 |
| 其他組合 | | | 照實寫，只寫「和……一致」 |

F2 支持的話，資料頻率也是因素之一，和上表並存。

限制：只有 24 個情境、計畫層、起點靜止；R_b、R_d 各取 BFS 的一條，平手的路線沒有列舉；F4 的參考軌跡由手工建構（等速、動作為 0），不完全像訓練資料。
